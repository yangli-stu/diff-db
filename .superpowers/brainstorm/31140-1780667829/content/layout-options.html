A: Fixed Top Panel

DB manager as a fixed-height scrollable panel at top. DB list uses tree-style inline expansion for tables. Compact toolbar for CRUD + Import/Export. Diff section below with Source/Target dropdowns (auto-populated from DB list).

Pros

  • Always visible, quick access
  • Familiar tree pattern (like IDEA Database tool)
  • Direct mapping: select DB in list → use in Source/Target

Cons

  • Fixed height may feel cramped with many DBs
  • Takes vertical space from diff view

B: Resizable Split Panel

DB manager as a resizable top section with a drag handle. Same tree-style expansion. Collapsible via toggle button. User controls how much space each section gets.

Pros

  • User controls vertical space allocation
  • Collapsible when not needed
  • Flexible for different workflows

Cons

  • More UI complexity (resize, collapse)
  • Requires more code (JBSplitter)
  • State persistence needed for split ratio

C: Compact Tag Bar + Expand Card

DBs shown as clickable tag chips in a horizontal bar. Click a chip to see its details (tables, actions) in a compact expandable card below. Very space-efficient.

Pros

  • Most space-efficient
  • Modern look (tag chips)
  • Maximizes diff view space

Cons

  • Unconventional for IDE plugins
  • Tables only visible one DB at a time
  • CRUD actions less discoverable
